## 🌟 Features
- **Engaging Narrative:** Jump and run through distinct "Worlds" representing my career progression from Intern to Lead Product Engineer.
- **Classic Mechanics:** Stomp enemies, collect power-up mushrooms, bump blocks, and gather coins.
- **Custom UI Popups:** Hitting specific "Info Blocks" pauses the game physics and displays a clean, readable resume modal.
- **Responsive Canvas:** Uses Kaboom's letterboxing to dynamically scale and play perfectly on both desktop monitors and smaller laptop screens.
- **Full Audio:** Authentic background music (BGM) and classic sound effects (SFX) that immerse the player.

## 🕹️ Controls

| Action | Key(s) |
| --- | --- |
| **Move Left** | `A` or `Left Arrow` |
| **Move Right** | `D` or `Right Arrow` |
| **Jump** | `W`, `Up Arrow`, or `Spacebar` |
| **Crouch** | `S` or `Down Arrow` |
| **Pause/Resume** | Click anywhere on the screen |

## 🛠️ Tech Stack & Architecture

- **Engine:** [Kaboom.js](https://kaboomjs.com/) - A fast, lightweight JavaScript game engine perfect for retro 2D games.
- **Frontend Core:** HTML5 & Vanilla CSS for the overarching layout, UI layer, and custom overlay modals (Start Screen, Info Blocks, Game Over).
- **Build Tool:** [Vite](https://vitejs.dev/) - Ensuring blazing fast local development and optimized production bundling.
- **Deployment:** Ready for GitHub Pages, Netlify, or Vercel.

## 🚀 Running Locally

Want to explore the source code or run the game on your local machine? It's simple!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vyommodi03/mario-resume.git
   cd mario-resume
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the Vite development server:**
   ```bash
   npm run dev
   ```

4. **Play!**
   Open `http://localhost:5173` in your browser.
